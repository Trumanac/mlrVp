mlrVp — User Guide

Overview

mlrVp is a grid-based sample looping instrument inspired by the original mlrV2.2 for monome. Load audio, trigger and loop samples from a grid controller (or the on-screen virtual grid), apply modular effects, and build setlists for live performance.

Supported grid controllers: monome grids (modern serialosc grids, legacy 40h/64 kit hardware via direct serial, and pre-serialosc devices via monomeserial); Novation Launchpads (all models); any generic MIDI note-on/off controller; and the built-in virtual grid. See the Monome Hardware & OSC section below for setup details.

Getting Started

  1. Open Setup → Audio and select your output device, then click Start Engine.
  2. Drag a WAV/AIFF/FLAC/OGG file onto any channel row's waveform area to load it.
  3. Set BPM in the transport bar to match your material.
  4. Click a cell on the virtual grid (or press a hardware grid button) to trigger playback.
  5. Hit SAVE in the transport to store the current state as a preset.

Channel Strips (Left Panel)

  • Each row is one sample channel. The waveform shows playback position, active selection (bright), out-of-loop content (dim), and grid column dividers.
  • Drag a file onto the waveform to load it. Dragging onto a playing row stages the new sample — the old audio keeps looping until the next trigger.
  • Mode (LOOP / PTCH / RVRS / SHOT / SLCE / SQNC / STEP, alphabetical) — Loop: continuous loop; Pitch: each grid column plays at a different pitch based on the selected scale map using duration-preserving pitch shifting (the sample plays at its original speed regardless of pitch); Reverse: reverse loop; Shot: one-shot to end; Slice: hold a button to play, hold two to latch a sub-loop; Sequence: step sequencer — toggle grid buttons to define active steps, the sample is divided into equal slices and each active step triggers its slice in sync with the clock; Step: press a button to play exactly the one slice it covers, once then stop — great for triggering individual hits or phrases without looping.
  • Group (G1–G4) — only one row per group plays at a time. Triggering a new row in the same group auto-stops the current one.
  • Speed spinner — playback rate (0.00–8.00×). −½ halves, +2× doubles. Snap Speed to Rate (Setup → Grid) rounds to the nearest ½×/2× step on load.
  • Pitch spinner — transpose in semitones (−24 to +24 st). Uses time-stretch pitch shifting so playback speed is unaffected. Computed in the background; audio switches seamlessly once ready.
  • Pitch mode controls (visible in PTCH mode only):
      • PITCH spinner — root offset in semitones (−24 to +24 st), shifts all scale pitches up or down.
      • SCALE selector — choose from Major, Minor, Pentatonic, Chord, or Chromatic scale maps (defines the pitch per grid column).
      • HOLD button — when active, the sample loops continuously on each pitch trigger instead of playing as a one-shot.

How it works: When entering Pitch mode (or changing scale/root/transpose/sample), mlrVp pre-computes pitch-shifted audio for each scale degree in the background using a phase vocoder. Each grid button triggers instantly from cache with zero real-time DSP cost. A rate-based fallback plays immediately if the cache entry is not yet ready. Only the columns your grid actually uses are computed (e.g. 8 for an 8-column grid).

Pitch Scale Maps

The SCALE selector determines which semitone intervals are assigned across the grid columns. All values are relative to the root (0 = unison). On an 8-column grid the first 8 entries are used; on 16 columns all 16 are used.

The root offset (PITCH spinner, −24 to +24 st) shifts every column's pitch by a fixed amount, transposing the entire keyboard. Changing the root, scale, transpose, or loading a new sample automatically rebuilds the pitch cache in the background.

  • Step spinner — number of equal slices (1–32) the sample is divided into for grid triggering. Locked to grid column count in SEQ mode.
  • Gain fader sets per-channel volume. Drag the waveform's start/end handles to set the active playback/loop region.
  • MUTE silences the channel without stopping it. STOP immediately ends playback.

Mixer (Right Panel → Mixer Tab)

  • G1–G4 faders — volume per group. Send fader — wet/dry amount sent to the FX bus.
  • FX route (OFF / FX1 / FX2 / FX3 / FX4) — choose which of the four independent send buses the group feeds. The button cycles through all options and displays the active bus in its group color.
  • AUX — aux send bus volume, mute, and FX route.
  • Master fader — final output level with stereo VU meter.
  • MUTE and STOP per group. Transport bar G1–G4 buttons are group stops; ALL stops everything.

Effects — FX Rack (Right Panel → Effects Tab)

The Effects tab contains a modular FX Rack with five independent effect groups: FX 1, FX 2, FX 3, FX 4, and MASTER. Click the tab buttons to switch between them. Each group can hold up to 8 modules (40 total across all five groups).

Default loadouts: FX 1 — Clean Studio (Compressor → Filter → Delay); FX 2 — Tape Warmth (Glue Compressor → Reel-to-Reel → Tape Delay); FX 3 — Space & Mod (Hall Reverb → Plate Reverb → Chorus); FX 4 — Lo-Fi / Destroy (Bit Crusher → Tube Overdrive → Vinyl); Master — Mastering (Glue Compressor → Multiband Filter → Oscilloscope).

Adding / Removing Modules

  • Click ＋ ADD EFFECT at the bottom of a rack. The menu shows all 40 modules with their effect type in parentheses — e.g. Byte Me (Bit Crusher).
  • Each module's right rack ear has two icons:
      • Power button (circle icon, top) — green = active, grey = bypassed. Click to toggle.
      • Remove ✕ (below power) — permanently removes the module.
  • Drag modules up/down to reorder them in the signal chain.

FX Routing

  • Each mixer group routes to OFF, FX1, FX2, FX3, or FX4. Each FX rack processes its own independent pre-mix send bus. The Master rack sits after all FX buses and processes the full mixed output — ideal for glue compression, EQ, and metering.
  • The Master Filter (HP/LP with resonance and response curve) sits above the mixer and applies to the master output.

MIDI MAP Mode

Click MIDI MAP in the FX Rack header to highlight all mappable controls (blue border). Click any highlighted control then move a hardware knob/fader to create a mapping. This is the same as Setup → MIDI → Learn — both stay in sync.

Tools (Right Panel → Tools Tab)

Record

Select a target Channel (1–16), input device, and length in bars (1–128). Enable Loop recording to overdub continuously or Input thru to monitor while armed. Click ARM and recording starts on the next beat, writing directly into the selected channel's sample buffer.

Sample Slicer

  1. Drag an audio file onto the waveform (or use the file dropdown).
  2. Select a bar count (1, 2, 4, 8, 16) and optionally enter a BPM (or leave on auto-detect).
  3. Click AUTO with FIT checked (default): start snaps to the nearest transient, end snaps to the nearest transient near the ideal bar boundary, both aligned to zero-crossings.
  4. Click SLICE + SAVE: the region is resampled to the exact sample count for the chosen bar length and saved to data/slices/. Every slice at the same BPM and bar count will be exactly the same duration — perfect for seamless looping at 1.0× speed.
  5. Uncheck FIT for classic mode: start snaps to a transient, end is calculated from BPM math only.
  6. Use ▶ Sel to preview the selected region through your cue (headphone) output. With Loop checked, moving the selection while playing queues the new region — it takes effect when the current loop finishes, so you hear a seamless transition. Stop and press ▶ Sel again to jump straight to the new selection.
  7. The SLICES library panel at the bottom lists all saved slices. Drag any entry onto a channel waveform to load it, or onto the slicer waveform to open it for editing. Click ✕ to delete (confirmation required).

Transport Bar

  • BPM — type a value or use the spinbox arrows (20–300 BPM).
  • SYNC — auto-detects BPM from the loaded samples and updates the tempo spinner.
  • TAP — tap repeatedly to set BPM by feel. Shows current beat position (e.g. 2.3) when idle.
  • Quantize — Off, 1/4, 1/8, 1/16, Bar. Controls when grid triggers fire.
  • P1–P4 pattern recorders — click to cycle idle → recording → playing. Click − / + arrows to change bar count freely between 1 and 32 bars (defaults: 2, 4, 8, 16). Hold the label 3 seconds to erase the pattern.
  • G1–G4 GROUP STOP buttons — stop all channels in that group. ALL stops all channels.

Presets and Setlists

  • Type a name in the PRESET box and click SAVE (flashes green on success).
  • Click ◀ / ▶ to step through the current setlist. Click NEW to clear everything.
  • Click the ⚙ gear button to open the Setlist Editor: reorder presets by dragging, add from the library, rename, or delete. Switch between named setlists from the dropdown.
  • Presets store the full state: channels, samples, effects, mixer, MIDI mappings, routing.

Setup (Right Panel → Setup Tab)

  • Audio tab — configure your audio hardware:
    • Driver Type — filter the device lists by host API (ASIO, WASAPI, CoreAudio, ALSA). Select a specific driver to see only its devices, or leave on All Drivers. On Windows, choose ASIO for lowest latency.
    • Output Device — your main audio output (speakers / interface).
    • Input Device — audio input for recording.
    • Sample Rate / Buffer Size — lower buffer = lower latency, higher CPU load.
    • Click Start Engine to open the audio stream. Use File → Restart to reinitialize after changing settings.
  • Grid tab — connect a hardware grid controller, set active rows and columns, toggle the virtual grid, and configure tilt mapping:
    • Monome Backend dropdown — choose how mlrVp talks to monome hardware:
      • Auto (default) — probes serialosc first; if serialosc is not running or the device does not enumerate (common with pre-2010 kit/40h hardware), falls back to 40h-direct
      • serialosc — explicitly use the serialosc daemon (required for all modern 2010+ monome grids). Install serialosc from github.com/monome/serialosc
      • 40h direct — bypasses serialosc and talks directly to the original 40h / black-rubber-64 kit hardware via FTDI serial (COM port, 9600 baud). Requires pyserial and the FTDI VCP driver. LEDs are binary on/off
      • Legacy OSC — connects to a running monomeserial bridge application using OSC/UDP (send port 8080, receive port 8000). Use run_monomeserial.bat (Windows) to launch with the correct environment pre-set
    • Grid Device — lists all discovered controllers. Click Scan for Controllers to refresh, then select a device and click Connect.
    • Show Virtual Grid — opens the on-screen grid in a separate window. Always available regardless of hardware.
    • Snap Speed to Rate — auto-rounds speed to the nearest ½×/2× step when loading a sample.
    • Tilt Control Mapping — enables the accelerometer/tilt section in the MIDI tab. Auto-enabled when a monome with a tilt sensor connects.
  • MIDI tab — add MIDI input controllers, click Learn to enter mapping mode. Each mapping row has Min/Max range and a Toggle checkbox. Tilt axis assignments appear here when a monome with accelerometer is connected.

Monome Hardware & OSC

Modern grids — serialosc (2010 and newer)

All current monome grids (grayscale 64 / 128 / 256 / walnut editions and newer) use the serialosc daemon. Install serialosc from github.com/monome/serialosc/releases, then set the Monome Backend to Auto or serialosc. mlrVp discovers devices automatically. Full LED brightness (off / dim / med / bright) and tilt/accelerometer are supported.

Windows tip: If serialosc is installed but the grid never appears, open Task Manager → Services → right-click serialosc → Start (or run net start serialosc as Administrator).

Original 40h / black-rubber-64 kit grids — 40h direct (2007–2009)

The original 40h kit and early black-rubber 64 boards use a binary serial protocol over FTDI USB. serialosc 1.4.x cannot enumerate these devices on Windows. Use the 40h direct backend to bypass serialosc and talk directly to the COM port.

  • Install the FTDI VCP driver so the device appears as a COM port (e.g. COM7)
  • Install pyserial: pip install pyserial
  • Set Monome Backend to 40h direct and click Scan for Controllers
  • If serialosc is running, mlrVp will request an elevated stop of the service to release the COM port

LED note: The 40h hardware has no PWM dimming — LEDs are binary on/off. mlrVp lights any brightness level ≥ 1 as ON so that sub-loop backgrounds and sequencer step dots remain visible.

Pre-serialosc grids via monomeserial — Legacy OSC

monomeserial is the original bridge application (pre-2010) that exposes a grid over OSC/UDP. If you already have monomeserial running, set the Monome Backend to Legacy OSC.

  • monomeserial sends button events to mlrVp on port 8000
  • mlrVp sends LED commands to monomeserial on port 8080
  • On Windows, use run_monomeserial.bat instead of run.bat — it pre-sets all required environment variables and calls the normal launcher

OSC Remote Control & Mirroring

mlrVp exposes a secondary OSC interface for remote control and visual mirroring (matching the serialosnoopy feature from mlrV2.2):

  • Receive port: 8001 — listens for incoming OSC control messages
  • Send port: 8000 — forwards mirrored events to any listening client
  • /mlrvp/grid/key x y state — mirrors every grid button press/release in real time
  • /mlrvp/position row pos — publishes per-channel playback positions continuously

This allows a second machine (or a visualiser in Processing, Max, or TouchDesigner) to receive the full grid state without being the primary grid controller.

Keyboard Shortcuts

  • Escape — exit MIDI learn mode
  • Ctrl+Shift+S — stop all audio
  • Ctrl+O — open preset file
  • Ctrl+S — save preset file
  • Ctrl+Q — quit

Slicer Keyboard Shortcuts (while the Slice panel has focus)

  • Space — audition the region under the cursor (or toggle play if no auto-chop regions)
  • Enter — play from current playhead position to end of selection
  • ← / → — step through auto-chop regions and audition each one
  • Shift+← / Shift+→ — nudge the active marker ±1 ms
  • Ctrl+Shift+← / Ctrl+Shift+→ — nudge the active marker ±1 sample
  • Ctrl+Z — undo last marker move
  • Ctrl+Shift+Z — redo last undone marker move

The active marker is whichever start or end handle was last dragged or edited via a spinbox.

File Menu

  • File → Open Preset File… — load a preset from any location on disk.
  • File → Save Preset File… — export the current state as a standalone JSON preset file for sharing.
  • File → Restart — reinitialize the audio engine and reload all settings. Use this after changing audio device settings or to recover from an audio dropout.
  • File → Stop All Audio — immediately stop all playing channels and pattern recorders.
  • File → Quit — close mlrVp.

View Menu

  • Show Virtual Grid — opens the on-screen grid controller in a separate moveable window.
  • UI Scale — resize the entire interface (50%–200%) to suit your monitor. The selected scale is saved and restored on next launch.
  • Lock Control Displays — keeps the value overlay permanently visible on every knob and fader. Useful when you want a live read of all parameters at a glance. Off by default.
  • Disable Control Displays — hides all value overlays entirely, including any you have latched on. Turning this off restores normal behaviour. Off by default.

Control Value Displays

Every knob and fader in mlrVp shows a floating value overlay when you interact with it:

  • Left-click and drag — overlay appears while you hold and drag, then fades after 1.2 seconds on release.
  • MIDI CC change — the knob or fader position updates visually and the value flashes for 1.2 seconds.
  • Right-click — toggles a per-control latch: the overlay stays on permanently until you right-click again to dismiss it. Useful for monitoring a single parameter during a performance.
  • Use View → Lock Control Displays to latch all controls at once, or View → Disable Control Displays to turn them all off.

Tips

  • Use FIT mode in the slicer to chop a track into perfectly looping 2-bar or 4-bar segments — they all land on the grid at 1.0× speed.
  • Drag a sample onto a playing row to stage it: the old audio keeps looping until you press a grid button on that row.
  • Power-bypass an FX module by clicking the green circle icon on its right rack ear — keeps the knob settings intact without removing the module.
  • The Twin Peaks VU meter has a mode selector: VU (ballistic needle), PEAK (fast attack/slow decay), or RMS (power average).
  • Both MIDI MAP buttons (FX Rack header and Setup → MIDI → Learn) are the same mode and stay in sync.

Slicer & Cue

The Slice tab (Tools panel) includes a dedicated cue output for headphone monitoring and advanced chopping tools:

  • Cue device — select a separate audio interface for preview. Choose a channel pair and set the cue volume (VOL fader) independently.
  • CUE ONLY / CUE+MAIN / OFF — controls whether preview audio goes to cue only, both outputs, or is muted.
  • ▶ Sel — play the selected region through the cue output. With Loop enabled, moving the selection queues the new region — it transitions seamlessly when the current loop iteration ends. Stop and re-press to jump directly to the new selection.
  • Slice mode: Manual (hand-placed markers), Transient (sensitivity-adjustable auto-detection), Equal (N divisions), and BPM Grid (beat boundaries). Click CHOP to create regions, audition each one, and EXPORT ALL to batch-save.
  • ZX snap — toggle zero-crossing snap so markers always land on a zero-crossing (eliminates clicks/pops at edit points).
  • GRID snap — toggle beat-grid snap so markers land on quarter-note boundaries based on the BPM setting.
  • Numeric spinboxes — type exact start/end/duration values in seconds (3 decimal places).
  • Undo / Redo — Ctrl+Z / Ctrl+Shift+Z to step through marker position history (up to 50 levels).
  • Marker nudge — Shift+Arrow = ±1 ms, Ctrl+Shift+Arrow = ±1 sample.

The Slices Library at the bottom lists all saved slices with search, sort, BPM badges, and right-click "Load to channel N". Hold Ctrl to multi-select, then batch delete.

Tip: Hover over any control in the slicer for a tooltip describing what it does.
